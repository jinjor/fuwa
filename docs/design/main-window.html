レーンは見るだけ

スロットを左に固めたぶん横幅が余るので、ノートを出す。編集ハンドルもグリッドのスナップもズームも置かない。直したいところは言葉で頼む。

識別は音源の名前に任せる

役割名も色分けも「誰が決めるのか」が未定なので、挿さっている音源の名前をそのまま出す。名前が読めれば足りるので、アイコンや色は要らない。

数字を消した

dB もサンプルレートもレイテンシも、見たところで何もしない。残したのは経過時間だけ。つまみは位置で覚える。

弾いたものは「添付」で渡す

トラックに録ってからクオンタイズで整える、という順序をやめる。録ったものはファイルとして残し、そのパスをプロンプトに差し込むだけ。グリッドに合わせるのは AI の仕事で、演奏が下手でも読み取ってもらう。

添付の口は端末の外

埋め込むのは claude / codex の素の端末なので、その入力欄の中にチップを描くことはできない。ボタンは端末の下に置く。止めた時点でファイルが作られ、そのパスが入力欄に入る。テイクを溜めて選ばせる画面は作らない。

会話は素の TUI

claude / codex の端末をそのまま埋める。自前のチャット UI を作ると、スラッシュコマンドも承認フローも作り直しになり、本家の変更に追随し続けることになる。
