# バックログ

## Step 0: 技術検証

「AI に C++ で VST3 ホストが書けるか」を確かめる。ここが最大の不確実性なので最初に潰す。駄目なら言語選定に戻る。

- ディレクトリ構成と責務境界の設計、およびそのお手本となる実装
- 開発ハーネスの整備（ASan / UBSan、リント、テスト、ビルド）
- CoreAudio によるオーディオ出力
- VST3 プラグインをロードして、ハードコードしたノートを鳴らす CLI 実行ファイル
- SDK 同梱のサンプルプラグインでの動作確認
- hostchecker による規格適合の確認
- 実世界のプラグイン（Dexed など）での動作確認

## MVP: AI がノートを打つと鳴る

AI に「ドレミファソを鳴らして」と頼むとノートが打たれて再生される状態。

- IPC サーバ
- ノート操作 API（トラックと小節範囲をアドレスとして扱えること）
- 再生制御 API
- Skill（AI に API の使い方を教える）

含まないもの: UI、保存、書き出し、複数トラック、ミキサー、テンポ変更。

## その先（優先度未定）

- 複数トラックとインストゥルメント
- WebView UI（トラック一覧・トランスポート・ミキサー）
- エージェントの起動と実行（プロセス管理・ストリーム受信・セッション継続）
- プロンプト入力バー
- 選択した範囲をプロンプトに渡す
- VST3 インストゥルメントの選択 UI とプラグインエディタの表示
- ミキサー（音量・パン）
- プロジェクトの保存形式
- オーディオ書き出し（wav / mp3 / ogg）
- MIDI 入力の添付（その場で弾いたメロディを AI に渡す）
- 音声入力の添付（要検討: エージェント側がオーディオを扱えないと成立しない）
